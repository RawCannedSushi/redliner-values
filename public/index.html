Google Drive inventory sync

This optional feature asks Google for permission to view and manage this app's private data folder in Google Drive. Redliner uses it for an inventory file. It cannot browse, read, or change your regular Drive files.

  • Your inventory still works locally without connecting Google.
  • Your inventory file is stored by Google, not in the Redliner history database.
  • Google's temporary access token stays in this page's memory and is not saved by this site or sent to its server.
  • Reconnect after closing the page or when access expires. After a successful sync, inventory changes upload automatically. Other devices' changes are loaded when you click Sync; this is not live collaboration.
  • If two devices have different copies, you choose which copy to keep. Cancel leaves both copies unchanged and pauses uploads. A conflicting cloud update also pauses uploads. Export a backup before your first sync.
  • Deleting the Google copy also disconnects sync on this page. Reconnecting can create a new copy. Disconnecting alone keeps both copies.

You can revoke access later in your Google Account's third-party connections. If sign-in is blocked inside Google Sites, open the website in a new tab to sync. That tab may have separate browser storage; export/import a backup to move inventory between the tab and this embed if necessary.

Reading values

Values are relative. For example, a skin listed at 200 has the same total listed value as two skins listed at 100 each.

200 = 100 + 100

Equal totals and similar demand generally make a fair trade. Consider demand alongside value before deciding. These figures are a general guide; actual trades can vary.
